Overview:
Campus Life Planner is an application made to help students especially in univesity to organize their academic tasks and balance them with their personal life.

Features:
-Add and manage tasks. -Set task durations and dealines. -Organize tasks using tags or categories. -Search and filter tasks. -Track task completion status. -Responsive and user-friendly interface.

Technologies Used:
-HTML5 -CSS3 -Javascript

Project Goal:
To help university student stay organized, manage their responsibilities, and balance academics with campus life.

Running the project:
Clone or download the repository.
Open the project in VS Code.
Run index.html using Live Server.
Open test.html with Live Server to run the tests.
Testing:
The test page checks validation, regex search, sorting, statistics, duration formatting, target validation, and data portability.

Accessibility:
The interface supports keyboard navigation, visible focus, semantic HTML, and reduced-motion preferences.

Data and privacy:
Records and settings are stored in the browser's localStorage. Export important data as JSON if you want a separate copy.

Limitations:
Data is stored locally in the browser and is not automatically synchronized across devices
